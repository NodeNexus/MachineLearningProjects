# Practical Notebook Header Rule

Whenever you are asked to create or update a Jupyter Notebook (`.ipynb`) for a practical or experiment in this workspace, ALWAYS ensure that the very first cell is a markdown cell containing the following student information pattern:

```markdown
**NAME-VAISHNAV BALPANDE\
SECTION-C2\
ROLL NO-B1-01\
SUBJECT-ML LAB\
PRACTICAL-[X]**
```

(Replace `[X]` with the correct practical number based on the folder name or context).
