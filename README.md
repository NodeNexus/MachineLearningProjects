# Machine Learning Lab Practicals

This repository contains Machine Learning practical assignments and their corresponding datasets. The practicals cover exploratory data analysis, data preprocessing, machine learning, and deep learning techniques using Python, Scikit-Learn, and TensorFlow.

## Repository Contents

### 1. Titanic Dataset Analysis (Prac1/PRAC1.ipynb)
- **Dataset:** 	itanic.csv
- **Description:** Exploratory Data Analysis (EDA) and preprocessing on the classic Titanic dataset. Handling missing values, visualizing survival rates, and preparing features.

### 2. USA Housing Price Prediction (Prac2/PRAC2.ipynb)
- **Dataset:** USA_Housing.csv
- **Description:** Predicting house prices based on various features such as area income, house age, number of rooms, and population.
- **Models Implemented:** Simple Linear Regression, Multiple Linear Regression, Ridge Regression, and Lasso Regression.

### 3. Concept Learning Algorithms (Prac3/PRAC3.ipynb)
- **Dataset:** Enjoy Sports dataset (enjoy.csv)
- **Description:** Implementation of fundamental concept learning algorithms (Find-S and Candidate Elimination) to derive specific and general hypotheses.

### 4. Wine Quality Analysis (Prac4/prac4.ipynb)
- **Dataset:** winequality-red.csv
- **Description:** Exploratory data analysis, feature scaling, and classification/regression modeling on red wine quality parameters.

### 5. K-Nearest Neighbors (KNN) Classifier (Prac5/Prac5.ipynb)
- **Dataset:** Pima Indians Diabetes dataset (diabetes.csv)
- **Description:** Implementation of K-Nearest Neighbors (KNN) algorithm for diabetes prediction, hyperparameter tuning for $, confusion matrix, and performance evaluation.

### 6. Artificial Neural Network (ANN) Classifier (Prac6/PRAC6.ipynb)
- **Dataset:** Wheat Seeds dataset (seeds_new.csv)
- **Description:** Multiclass classification of wheat seed varieties using Artificial Neural Networks (ANN) built with TensorFlow/Keras. Includes data preprocessing, feature scaling, model training with Early Stopping, accuracy/loss visualization, and confusion matrix evaluation.

### 7. Naïve Bayes Classifier (Prac7/PRAC7.ipynb)
- **Dataset:** Raisin dataset (Raisin_Dataset.xlsx)
- **Description:** Implementation of Gaussian Naïve Bayes algorithm for classifying raisin varieties (Kecimen vs. Besni). Includes EDA, distribution visualizations, evaluation using precision, recall, F1-score, confusion matrix, ar_smoothing hyperparameter tuning, and custom sample inference.
